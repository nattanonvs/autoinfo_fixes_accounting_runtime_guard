# User Guide

## สำหรับใคร

เอกสารนี้สำหรับแอดมินระบบ

## วิธีใช้

1. เปิดเมนู `Runtime Guard`
2. กด `Run Checks`
3. เปิดรายการที่ขึ้น `warning` หรือ `error`
4. กด `Open Fix Help`
5. คัดลอกคำสั่งไปใช้
6. กลับมากด `Mark Reviewed` เมื่อดำเนินการแล้ว

## หมายเหตุ

- ระบบนี้ช่วยตรวจและสรุปปัญหา
- ระบบนี้ไม่แก้ environment ภายนอกให้อัตโนมัติ
