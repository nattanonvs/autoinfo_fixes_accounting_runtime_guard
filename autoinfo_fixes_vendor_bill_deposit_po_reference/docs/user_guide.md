# คู่มือผู้ใช้

## ใช้งานเมื่อไร
- ใช้ตอนสร้าง `Vendor Bill`
- และเลือก `Type = Deposit Payment`

## วิธีใช้
1. เปิดเอกสาร `Vendor Bill`
2. เลือก `Type = Deposit Payment`
3. ระบบจะแสดงช่อง `PO Reference`
4. ระบบจะแสดงเฉพาะ PO ของคู่ค้าเดียวกัน และเป็น PO ที่ยืนยันแล้ว
5. เลือกใบสั่งซื้อที่ต้องการอ้างอิง
6. ใช้งานปุ่ม deposit เดิมได้ตามปกติ

## หมายเหตุ
- ฝั่ง `Customer Invoice` ยังใช้ `SO Reference` เหมือนเดิม
- ใน `SO Reference` ระบบจะแสดงเฉพาะ SO ของคู่ค้าเดียวกัน และเป็น SO ที่ยืนยันแล้ว
